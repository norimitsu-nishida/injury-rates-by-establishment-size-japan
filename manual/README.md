# manual/

`manual_estat.md` の手順でブラウザから落とした e-Stat の表を、`reg_2021.xlsx` のような名前でここに置く。
`08_manual_estat.R` が読んで API の値と突き合わせる。

## 検収の記録
- 2026-10-09 西田: reg 6表(2009・2012・2014・2016・2021・2024)と ind 2表(2009・2021)を `manual_estat.md` の手順で e-Stat からブラウザで取得し、`08_manual_estat.R` で API の値と突き合わせた。reg は全産業×6区分(36セル)、ind は12業種群×6区分(144セル)がすべて一致。
- 2026-10-09 西田: 2014年(基準年)について、`manual/reg_2014.xlsx` を6区分に畳んだ分母と、確定値ワークシート⑤業種・規模の「合計−官公署」の分子から Excel で率を計算し、Table 4・5 の 2014 の行(死亡率 2.17 / 3.66 / 2.94 / 2.48 / 1.63 / 1.11 / 0.34、報告死傷率 245 / 273 / 264 / 318 / 259 / 249 / 119)と完全一致。
- 2026-10-10: 業種の対応表を労災統計の業種分類に合わせて9群に組み替えたあと、同じ手取得の ind 2表を `08_manual_estat.R` で再照合し、9業種群×6区分(108セル)がすべて一致。洗濯・浴場・映画館などの小分類の振り替え分は API の全産業表(小分類×規模)から当てている。
